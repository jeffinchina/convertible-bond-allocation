# 可转债配债分析微服务产品规格说明书

版本：1.2.7
更新日期：2026-10-16
产品目录：`work/bond_analysis_service/`

## 1. 产品目标

用户输入 A 股简称、六位代码或固定范式“帮我分析四方科技的配债数据”，系统独立抓取申报文件、股本和行情，生成与自动日报一致口径的 HTML/JSON 配债关键数据报告。全流程为确定性程序，不调用模型、不消耗模型用量。

## 2. 使用入口

- 桌面入口：双击 `配债数据分析.cmd`，启动器按自身目录定位 PowerShell 脚本，不包含本机用户名或绝对路径；浏览器打开 `http://127.0.0.1:8765/`。
- 命令行：`py work/bond_analysis_service/service.py --analyze "股票名称或代码" --open`
- API：`POST /api/analyze`，JSON 请求示例：`{"query":"四方科技"}`。
- 健康检查：`GET /health`，当前接口版本为 3，服务标识为 `BondAnalysisService/1.2.7`。

## 3. 分析流程

1. 解析股票名称或代码，要求唯一匹配 A 股。
   股票联想查询使用东方财富公开行情网页固定携带的客户端标识；该值不关联个人账户、不授予登录或写入权限，不属于本机凭据。真正的令牌、Cookie 和私有配置不得进入源码。
2. 检索最新可得的募集说明书注册稿、修订稿或预案，并保存 PDF 和查询原始数据。巨潮查询优先使用主站；遇到 403、传输失败或无效 JSON 时自动切换官方 `list.cninfo.com.cn` 备用域名。同一次分析复用已成功端点，主备均失败时返回完整性错误。
3. 提取募集规模上限及官方股本快照；与最新行情股本交叉核验。金额解析覆盖“募集资金总额”“预计募集资金量（含发行费用）”“募集资金不超过”“拟发行可转换债券的金额”“本次发行总额为人民币 X 万元”等注册稿及正式文件常见表述，并要求可转债发行上下文以避免误取无关金额。共享正式解析器会对全部金额候选做语义排序：明确的本次最终发行总额优先，带调减、扣减、原拟、调整前、变更前等调整或历史上下文的金额不得覆盖当前金额。股本候选覆盖“股本总额”和“可参与原股东优先配售的股本总额/数量”；在发行额和每股配售额可得时，以 0.5% 一致性阈值选择真实可参与配售基数。正式日程解析兼容 PDF 表格按列压平的情况：带 `T-1` 的日期与近距离股权登记日事项优先绑定，防止把下一行 `T` 日申购日误当登记日。
4. 获取公司概况的末级细分行业，以及最新报告期主营构成中收入占比最高的产品类别；无产品类别时回退业务类别，排除“其他”。公司概况短暂不可用时，行业依次回退行情行业字段和最新主营构成行业类别；自动识别未声明的 gzip 正文，接口空正文执行三次内容级重试。
5. 获取上一交易日不复权收盘价、前 20 日成交额和成交量、短期收益及波动。
   盘中查询会主动剔除当日未收盘 K 线。
6. 通过完整性闸门后执行确定性计算，生成 HTML 和 JSON 报告。

巨潮 PDF 附件只通过 HTTPS 下载。标准客户端受 CDN 限制时，使用 `curl_cffi` Chrome 兼容 HTTPS 通道；不会为了“补齐”报告降级至明文 HTTP。传输方式、是否回退和首通道错误均写入附件下载审计。

## 4. 输出字段与公式

| 指标 | 公式或来源 |
|---|---|
| 行业｜主营业务 | 关键数据表第一条数据行；同一数值单元格内行业在第一行、主营业务在第二行；两项各不超过 10 个字符 |
| 募集规模上限 | 最新可得正式申报文件 |
| 最新总股本 | 行情股本快照，必要时回退官方文件 |
| 最近收盘价 S | 上一交易日不复权收盘价 |
| 参考转股价下限 P0 | `max（前20日成交总额÷成交总量，前1日成交总额÷成交总量）`，向上取整到 0.01 元 |
| 正股现价/转股价 | `S ÷ P0 × 100`，报告显示 0 位小数 |
| 理论每股配债 p | `募集规模上限 ÷ 最新总股本` |
| 每100股理论可配面值 | `100 × p` |
| 理论百元含权率 | `p ÷ S × 100%` |
| 理论配1手所需股数 N0 | `1000 ÷ p` |
| 保守稳1手股数 N | `ceil(N0 ÷ 100) × 100` |
| 对应正股资金 M | `N × S` |
| 每千元转债/正股资金 H | `1000 ÷ M` |
| 正股盈亏平衡跌幅 D* | `H × 假设转债上市涨幅` |

### 4.1 转股价口径

在正式发行公告发布前，实际初始转股价尚未确定，报告明确写作“参考转股价下限”。正股现价/转股价用于衡量当前股价相对法定定价基准的位置，不代表未来实际转股价值。正式发行后应使用发行公告中的实际初始转股价重新分析。

## 5. 完整性闸门

以下任一字段缺失时，状态返回 `incomplete`，HTML 不输出伪完整计算：

- 公司细分行业或主营业务；
- 募集规模；
- 最新总股本；
- 上一交易日收盘价；
- 20 个有效交易日的成交额和成交量，无法计算参考转股价。

报告保存关键输入、来源链接、警告和原始证据，便于复核。

共享正式文件解析遵循 fail-closed：同一字段在多份官方文件中冲突，或 `发行额` 与 `可配售股本 × 每股配售额` 的差异超过 0.5%，均不得输出伪完整结果。微服务当前入口主要分析正式发行前估算，但复用的金额和股本解析应与自动日报保持一致。

金额冲突比较只使用经过当前/历史语义筛选的候选：募投项目调减额、旧方案金额和调整前金额不会制造伪冲突；真正的当前发行额冲突仍保持 fail-closed。

## 6. 数据与文件

- HTML：`work/bond_analysis_service/reports/<报告ID>/report.html`
- JSON：`work/bond_analysis_service/reports/<报告ID>/report.json`
- 原始证据：同目录下 `artifacts/`
- 巨潮查询审计：`artifacts/supplemental-cninfo-query.json`，其中 `_fetchMeta` 记录主站/备用域名选择和失败原因。
- 公司概况原始响应：`artifacts/company-survey-raw.json`
- 主营构成原始响应：`artifacts/business-analysis-raw.json`
- 行业备用响应：`artifacts/company-industry-fallback-raw.json`（仅触发回退时生成）
- 标准化行业主营：`artifacts/company-profile.json`（同时写入报告 JSON 的 `calculation.companyProfile`）
- 主程序：`work/bond_analysis_service/service.py`
- 公共计算：复用 `work/hybrid_monitor/monitor.py`
- Python 依赖：`work/hybrid_monitor/requirements.txt`

## 7. 维护与验收

- 测试：`py work/bond_analysis_service/test_service.py`（当前 7 项）与 `py work/hybrid_monitor/test_monitor.py`（执行全部用例）。
- 修改共享计算后必须同时回归自动日报和微服务。
- 验收重点：“行业｜主营业务”必须是关键数据表第一条数据行且只占一个指标行，数值单元格内行业在上、主营业务在下，行业和主营各不超过 10 个字符；报告同时显示参考转股价下限、正股现价/转股价；比率显示 0 位小数；JSON 保留原始行业主营、未取整比率和两段成交均价；任一关键字段缺失时触发完整性闸门；共享金额句式与正式股本候选择优变更后必须同时执行 7 项服务测试和全部共享模块测试。莱特光电 `688150` 共享解析回归必须选择最终发行额 524,779,000 元而非历史调减额 68,000,000 元，并识别 399,439,136 股可参与优配基数。

## 8. 边界

服务只监听本机 `127.0.0.1`，不对外网开放。结果用于数据分析，不构成投资建议；正式发行文件发布后必须以实际发行参数重算。
