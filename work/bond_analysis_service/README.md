# 配债关键数据分析微服务

本服务复用每日监控的正式发行前补证和确定性计算模块。输入 A 股名称、六位代码，或固定范式“帮我分析四方科技的配债数据”，即可生成与润禾材料邮件中“关键数据与计算”一致口径的 HTML/JSON 报告。若尚无注册稿，会使用最新可得的正式预案或募集说明书，并在报告中保留实际文件标题和日期，不会把预案阶段误写成已注册。

## 桌面入口

双击桌面的 `配债数据分析.cmd`，浏览器会打开 `http://127.0.0.1:8765/`。输入股票名称或代码后点击“生成报告”。服务仅监听本机回环地址，电脑重启后再次双击入口即可。

## HTTP 接口

```text
GET  /health
POST /api/analyze
Content-Type: application/json

{"query":"帮我分析四方科技的配债数据"}
```

成功响应包含计算结果、证据来源、HTML 报告路径和 JSON 报告路径。募集规模上限、总股本或最近行情任一关键字段缺失时，`status` 为 `incomplete`，不会输出伪完整计算。

报告关键数据表第一条数据行显示合并字段“行业｜主营业务”，同一单元格内行业、主营业务上下两行展示，两项各不超过 10 个字符；同时给出正式发行前的参考转股价下限，以及“上一交易日正股收盘价/参考转股价下限”。参考转股价取前 20 日成交均价与前 1 日成交均价的较高者；实际初始转股价仍以正式发行公告为准。

## 命令行入口

```powershell
py .\service.py --analyze "四方科技" --open
```

报告和补证原始文件保存在 `reports/<时间戳_代码>/` 下。

完整产品口径见 `../../docs/可转债配债分析微服务产品规格说明书.md`，版本变化见 `../../docs/可转债配债分析微服务更新记录.md`。
