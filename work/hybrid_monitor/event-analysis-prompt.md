# 可转债配债事件日深度分析任务

你只处理给定事件清单列出的证据包。每个 `evidence.json` 对应一家公司、一个公告阶段，包含三层来源匹配、原始链接和已下载文件。一天有多个项目时也只运行本次模型一次，但每家公司仍生成一封标题格式严格的邮件。

## 必须遵守

1. 先读取证据 JSON，再读取其中列出的本地公告正文/PDF；不要把文件名或搜索摘要当作公告事实。证据包中的 `calculation` 由脚本取数、计算并校验，优先级高于模型自行搜索或计算。
2. 证据优先级固定：上交所/深交所原始公告 > 巨潮资讯同一公告 > 中国证监会注册结果或交易所审核项目页。事实冲突时采用交易所原始公告，并明确列出差异。
3. 只使用可核验事实，不能估造。注册或正式发行阶段若 `calculation.status` 不是 `complete`，流程应当失败并发送异常通知，不允许生成带有关键行情“待补证”的低价值分析邮件。
4. 不保证收益，不给直接买卖指令，只给条件式结论。
5. 最终只输出一个 JSON 对象，顶层只有 `emails` 数组。每个证据包对应一个邮件对象，字段必须是：`subject`、`htmlBody`、`stage`、`company`、`code`、`evidenceUsed`、`warnings`。
6. 不要用 Markdown 代码围栏包裹 JSON。

## 标题

- 注册批复：`【可转债配债】同意注册公告：股票简称`
- 正式发行：`【可转债配债】正式发行公告：股票简称`

## 正文结构

第一段用不超过三行给出摘要，然后依次写：公告事实、三层交叉核验、关键数据与计算、情景压力测试、风险、条件式结论。每个事实注明数据日期和直达链接。

“关键数据与计算”不得由模型重新编数字或改公式。`companyProfile` 是脚本从公司概况和最新主营构成中取得并校验的“行业｜主营业务”，两项各不超过10个字。注册和正式发行两个阶段都必须在公告事实之后把占位符 `[[CALCULATION_TABLE:证券代码]]`（例如 `[[CALCULATION_TABLE:300727]]`）作为独立文本直接输出，不要用 `<h3>`、`<p>` 或其他标签包裹；运行器会用证据包内已经校验的 `calculation.html` 替换，其中已包含行业与主营业务首行。不得在占位符之外另写一个重复的“关键数据与计算”章节。

### 同意注册阶段

陈述公司、代码、交易所、公告日期和标题、公告编号、证监许可文号、批复有效期、注册额度上限、募集资金用途及官方链接。

脚本会在醒目的“早期估算”区域提供并核验：

- 注册稿中的募集规模上限、最新总股本和最近交易日不复权收盘价，并写明日期和来源；
- `p = 注册额度上限 / 最新总股本`（元/股）；
- 每100股理论可配面值 `100p`；
- 理论含权率 `p / 正股价格`；
- `N0 = 1000 / p`；
- 保守稳1手股数 `N = 100 × ceil(N0 / 100)`；
- `M = N × 正股价格`；
- `H = 1000 / M`；
- 按转债上市涨幅 15%、20%、30%、40%、50%列出 `D* ≈ H × g`。

模型必须解释脚本计算结果的含义、敏感性和局限，不得用“证据包没有数据”替代分析。必须说明：这些数字是早期估算，最终发行规模、实际优先配售比例、股权登记日、申购日、转股价和最低稳配股数尚未确定，不能当成确定配售资格。最后说明是否进入候选池，下一触发点是正式发行公告。

### 正式发行阶段

陈述正股代码、转债简称/代码、公告日、股权登记日、申购日、最终发行规模、总股本/可配售股份基数、每股优先配售金额、初始转股价、评级、期限、原股东配售代码和缴款要求、官方链接。

“关键数据与计算”由运行器以三列表格（项目、数值、口径与日期）注入。模型不要自行生成表格或“行业｜主营业务”行，只解释脚本计算结果的含义、敏感性和局限。

完成：

- 使用发行公告的实际每股配售额 `p`；
- 使用最新可得正股收盘价 `S`，同时列公告日前一交易日和股权登记日前最新价格；
- `N0 = 1000 / p`；
- 区分“博1手”区间与沪市尾数进位/深市张数规则，不把不确定进位写成保证；
- 按相应市场真实配售规则计算保守稳1手股数和 `M`；
- `H = 1000 / M`，百元含权 `= 100p / S`；
- 转股价值 `= 100 × 正股价格 / 初始转股价`；
- 参考同评级、同行业、相近转股价值的转债，给保守/中性/乐观三种上市价格情景；若证据不足，明确该项待补证，不可伪造可比样本；
- 总收益 `= 1000 × 转债预计上市涨幅 - M × 正股跌幅 - 交易成本`；
- `D* = (1000 / M) × 转债预计上市涨幅 - 交易成本 / M`；
- 至少列 15%、20%、30%、40%、50%转债涨幅下的 `D*`；
- 对公告前10/20日累计涨幅、波动率和抢权兑现风险做压力测试，并给“正股达到什么价格后不再划算”的条件阈值。

最终结论只能是：值得进一步研究 / 安全边际不足 / 不建议仅为配债参与，并写出成立条件。
